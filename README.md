# 🎁 podarky_bot — Telegram-бот розыгрыша подарков

Воронка: **запуск → бросок кубика → подарок → 10 скриншотов → подписка на спонсоров → оплата 1 ₽ → подтверждение участия.**

Обычный Telegram-бот (не Mini App). Python 3.11+, aiogram 3, SQLite.

## Структура

```
main.py               — запуск: polling + вебхук оплаты
app/config.py          — конфигурация из .env
app/db.py              — SQLite (users, gifts, sponsors, settings, events)
app/webhook.py         — GET /paid — подтверждение оплаты с сайта
app/bot/handlers.py    — пользовательская воронка (5 шагов)
app/bot/admin.py       — админ-панель в Telegram (/admin)
app/bot/keyboards.py   — все клавиатуры
app/bot/texts.py       — дефолтные тексты (правятся в админке)
scripts/smoke_test.py  — смоук-тест без Telegram
```

## Установка и запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN, ADMIN_IDS, PAYMENT_URL
.venv/bin/python main.py
```

Проверка без Telegram:

```bash
.venv/bin/python scripts/smoke_test.py
```

## Шаги пользователя

| # | Шаг | Как работает |
|---|-----|--------------|
| 1 | Запуск | `/start` → картинка с 6 подарками, кнопки «Бросить кубик» и «Посмотреть отзывы» |
| 2 | Подарок | Бот кидает настоящий 🎲, выпавшее число (1–6) выбирает подарок; отправляется картинка и ссылка на коллекционный подарок |
| 3 | Задание | Пользователь присылает 10 скриншотов комментариев под видео; бот считает прогресс |
| 4 | Спонсоры | Кнопки на каналы + «Проверить подписку» → `get_chat_member` для каждого канала |
| 5 | Оплата | Кнопка на внешний сайт (1 ₽); после оплаты сайт дёргает вебхук → участник получает подтверждение |

Условия розыгрыша и отзывы доступны всегда — кнопки внизу и в первом сообщении.

## Админ-панель: `/admin`

- 📊 **Статистика** — всего участников и конверсия по каждому этапу воронки
- 📝 **Тексты** — редактирование всех текстов бота (хранятся в БД)
- 🎁 **Подарки** — названия и ссылки 6 подарков
- 👥 **Спонсоры** — добавление/удаление каналов
- 🖼 **Картинка** — загрузка картинки с 6 подарками
- 💰 **Оплата** — URL платёжной страницы
- 📢 **Рассылка** всем участникам
- 🔄 **Сброс участника** на первый этап

## Интеграция с сайтом оплаты

Кнопка «Оформить подписку» ведёт на `PAYMENT_URL`; в URL автоматически подставляется
`tg_user=<id>` (или плейсхолдер `{user_id}`, если он есть в URL).

После успешной оплаты ваш сайт должен вызвать:

```
GET https://<ваш-домен>:8081/paid?user_id=123456&token=PAYMENT_WEBHOOK_TOKEN
```

Ответ: `{"ok": true}`. Бот сразу отправит участнику подтверждение и уведомит администраторов.
Для локальной разработки используйте ngrok/cloudflared и укажите публичный URL в `WEBHOOK_*`.

## Данные для проверки подписки

Бот должен быть **администратором** каждого спонсорского канала (право «Просмотр участников» достаточно).
В админке спонсор добавляется как `@channel | Название | https://t.me/channel`.

## Переменные окружения (.env)

См. [.env.example](.env.example): `BOT_TOKEN`, `ADMIN_IDS`, `PAYMENT_URL`, `PAYMENT_AMOUNT`,
`PAYMENT_WEBHOOK_TOKEN`, `WEBHOOK_HOST`, `WEBHOOK_PORT`, `DB_PATH`.
